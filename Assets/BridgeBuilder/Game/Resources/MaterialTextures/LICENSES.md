# Material textures

The color (albedo) map from each ambientCG 1K JPG pack, kept under its original file name. `BridgeView` loads
them with `Resources.Load<Texture2D>("MaterialTextures/<file name without extension>")`. No other maps from the
packs are used.

| File | Used for | Asset page | Downloaded from |
| --- | --- | --- | --- |
| `Wood049_1K-JPG_Color.jpg` | Wood beams and wood decks | https://ambientcg.com/a/Wood049 | https://ambientcg.com/get?file=Wood049_1K-JPG.zip |
| `Rope002_1K-JPG_Color.jpg` | Steel cable | https://ambientcg.com/a/Rope002 | https://ambientcg.com/get?file=Rope002_1K-JPG.zip |
| `Concrete034_1K-JPG_Color.jpg` | Concrete beams and concrete decks | https://ambientcg.com/a/Concrete034 | https://ambientcg.com/get?file=Concrete034_1K-JPG.zip |
